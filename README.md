## Description

This repository contains several low-level programming projects written in C, exploring fundamental concepts such as loops, conditions, functions, memory management, and data structures.  
The projects are designed to help build a deep understanding of the C language and its practical applications.

----------

## Repository Structure

-   **`hello_world`**: Introduction to C programming, basic programs, compilation, and output display.
-   **`variables_if_else_while`**: Use of variables, conditional statements, and control loops.
-   **`functions_nested_loops`**: Learning functions, nested loops, and program structure.
-   **`more_functions_nested_loops`**: Advanced functions and loops for solving more complex problems.
-   **`pointers_arrays_strings`**: Manipulating pointers, arrays, and strings in C.
-   **`malloc_free`**: Dynamic memory allocation and deallocation using `malloc` and `free`.
-   **`variadic_functions`**: Handling functions with variable numbers of arguments.
-   **`linked_lists`**: Implementation and manipulation of singly and doubly linked lists.
-   **`file_io`**: File input and output operations in C.

----------

## Learning Objectives

Through these projects, the following key programming skills are covered:

-   Understanding the basic syntax and structure of the C language.
-   Mastering the use of loops, conditions, and control structures.
-   Structuring code efficiently using functions.
-   Managing memory dynamically and understanding pointers.
-   Manipulating arrays and strings effectively.
-   Implementing data structures such as linked lists.

## Compilation and Execution

All C files should be compiled with `gcc` using the following flags:

```c
gcc -Wall -Werror -Wextra -pedantic -std=gnu89 <file.c> -o <output>
```
To execute the compiled program:
```bash
./<output>
```

## Requirements

-   All code must adhere to the **Betty coding style**.
-   Each file must end with a **newline**.
-   Only the following editors are allowed: `vi`, `vim`, or `emacs`.
