# C - Hello, World

## Description

The "C - Hello, World" project is designed to introduce you to the C programming language and familiarize you with its basic concepts, including compiling programs, printing output, and understanding the structure of a C program.

### Learning Objectives

By the end of this project, you should be able to explain the following concepts:

- Why C programming is awesome and its historical significance.
- The role of Dennis Ritchie, Brian Kernighan, and Linus Torvalds in the development of C.
- The process of compiling C programs using `gcc` and understanding the meaning of `gcc main.c`.
- The concept of an entry point in a program, specifically `main`.
- How to print text using functions such as `printf`, `puts`, and `putchar`.
- How to get the size of a specific type using the `sizeof` operator.
- How to compile C code using `gcc` and understand the default program name.
- The official C coding style and how to check your code with the Betty style.
- The role of headers when using standard library functions.
- How the return value of the program is influenced by the `main` function.

## Requirements

### General Requirements:

- Allowed editors: `vi`, `vim`, `emacs`.
- All your files will be compiled on Ubuntu 20.04 LTS using `gcc` with the following options: `-Wall -Werror -Wextra -pedantic -std=gnu89`.
- Your files should end with a new line.
- A `README.md` file should be placed at the root of your project repository, describing the project and its purpose.
- There should be no errors or warnings during compilation.
- You are not allowed to use `system` in your code.
- Your code should follow the Betty style, and it will be checked using `betty-style.pl` and `betty-doc.pl`.

### Shell Scripts Requirements:

- Allowed editors: `vi`, `vim`, `emacs`.
- Scripts will be tested on Ubuntu 20.04 LTS.
- Scripts must be exactly two lines long (`$ wc -l file` should print `2`).
- Each file should end with a new line.
- The first line of all scripts should be `#!/bin/bash`.

## Betty Linter

To ensure your code follows the Betty style, you can use the `betty` linter. To set it up:

1. Clone the Betty repository.
2. Run the installation script.
3. Use `betty <filename>` to check your code.

You can find more information on setting up the Betty linter and using it in the official instructions.

## Conclusion

This project is a beginner's introduction to the C programming language. It provides the foundational knowledge necessary for further exploration and development in C. By completing this project, you will have a solid understanding of C's syntax, compiling process, and basic output methods.
