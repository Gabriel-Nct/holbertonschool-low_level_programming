# C - Functions, Nested Loops

## Description

The "C - Functions, Nested Loops" project introduces two essential programming concepts in C: functions and nested loops. This project aims to help you understand the purpose of functions, how to define and declare them, how to use nested loops, and how to structure your code efficiently.

### Learning Objectives

By the end of this project, you should be able to explain and use the following concepts:

- **Nested Loops**: Learn what nested loops are and how to use them effectively.
- **Functions**: Understand the concept of functions and how to use them in C.
  - Understand the difference between a function declaration and a function definition.
  - Learn about function prototypes and why they are important.
- **Scope of Variables**: Understand how variable scope works in C, and how variables are accessible within functions.
- **GCC Flags**: Understand the GCC compiler flags `-Wall -Werror -pedantic -Wextra -std=gnu89`.
- **Header Files**: Learn how to use header files and the `#include` directive to manage function prototypes.

### Resources

Here are the resources to help you succeed in this project:

- **Nested while loops**: Learn about using loops inside other loops.
- **C - Functions**: Understand how functions work in C, including how to declare, define, and call functions.
- **Learning to Program in C (Part 06)**: Watch this video to learn more about functions.

### Requirements

#### General Requirements:

- Allowed editors: `vi`, `vim`, `emacs`.
- All your files will be compiled on Ubuntu 20.04 LTS using `gcc` with the following options: `-Wall -Werror -Wextra -pedantic -std=gnu89`.
- Your files should end with a new line.
- A `README.md` file should be placed at the root of your project folder, describing the project and its objectives.
- There should be no errors or warnings during compilation.
- You are not allowed to use global variables.
- No more than 5 functions per file.
- You are not allowed to use functions like `printf`, `puts`, or any other standard library functions. Use `write` or `_putchar` for output.
- You are allowed to use `_putchar`, but do not push your own version of `_putchar.c` (it will be used from the course repository).
- The prototypes of all your functions, including `_putchar`, should be included in your header file called `main.h`.
- Push your `main.h` header file to the repository.

### Conclusion

This project will teach you essential programming techniques in C, focusing on functions and loops. By mastering these concepts, you will be able to structure your code more efficiently and handle more complex problems in the future.
