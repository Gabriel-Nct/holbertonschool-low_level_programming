# C - More Functions, More Nested Loops

## Description

The "C - More Functions, More Nested Loops" project builds upon the previous concepts of functions and nested loops in C. This project delves deeper into writing more complex functions and using multiple levels of loops to solve problems. You will learn how to manage multiple nested loops and how to structure and prototype your functions efficiently.

### Learning Objectives

By the end of this project, you should be able to:

- **Nested Loops**: Understand how to use multiple nested loops and how they can be applied to different problems.
- **Functions**: Understand the deeper concepts of functions in C, including declarations, definitions, and prototypes.
  - Understand the difference between a function declaration and a function definition.
  - Learn how to use function prototypes.
- **Variable Scope**: Gain a deeper understanding of variable scope and how variables are used within functions.
- **GCC Flags**: Understand the purpose of the GCC compiler flags `-Wall -Werror -pedantic -Wextra -std=gnu89`.
- **Header Files**: Learn how to structure your code using header files with the `#include` directive, and understand how to define function prototypes in header files.

### Resources

The following resources will guide you through the project:

- **Nested while loops**: Learn how to implement and use nested `while` loops.
- **C - Functions**: Deepen your understanding of functions, their definitions, declarations, and prototypes.
- **Learning to Program in C (Part 06)**: Watch the video to reinforce your understanding of functions (stop at 14:00).
- **Function Prototypes**: Learn the importance of function prototypes in C and how to use them.

### Requirements

#### General Requirements:

- Allowed editors: `vi`, `vim`, `emacs`.
- All files will be compiled on Ubuntu 20.04 LTS using `gcc` with the options: `-Wall -Werror -Wextra -pedantic -std=gnu89`.
- Your files should end with a new line.
- A `README.md` file must be present in the root folder of your project, explaining the purpose and details of the project.
- There should be no errors or warnings during compilation.
- Global variables are not allowed.
- No more than 5 functions per file.
- The use of standard library functions such as `printf`, `puts`, etc., is strictly forbidden. You may use `_putchar` for output.
- You are allowed to use the `_putchar` function, but do not push your own version of `_putchar.c` to the repository. It will be provided for you.
- You do not need to push `main.c` files; they are only for testing purposes.
- All function prototypes, including `_putchar`, should be included in your header file `main.h`.
- Ensure that your `main.h` header file is included in the repository.

### Conclusion

This project will help you build a stronger foundation in C by expanding your knowledge of functions, nested loops, and variable scope. By completing this project, you will be better equipped to write more complex and organized C programs.
