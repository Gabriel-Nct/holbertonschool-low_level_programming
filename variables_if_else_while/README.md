# C - Variables, if, else, while

## Description

The "C - Variables, if, else, while" project is designed to introduce you to the basic concepts of C programming, including variables, control structures like `if` statements, `else`, and `while` loops. You will also learn about arithmetic, logical, and relational operators, as well as the ASCII character set.

### Learning Objectives

By the end of this project, you should be able to explain the following concepts:

- **Arithmetic Operators**: Understand and use operators like `+`, `-`, `*`, `/`, and `%`.
- **Logical Operators**: Understand the usage of `&&`, `||`, and `!` in conditional expressions.
- **Relational Operators**: Use operators such as `==`, `!=`, `>`, `<`, `>=`, and `<=` for comparisons.
- **TRUE and FALSE**: Understand the values considered as TRUE (`1`) and FALSE (`0`) in C.
- **Boolean Operators**: Know how to use boolean logic with `&&`, `||`, and `!`.
- **if, if...else Statements**: Use these control flow statements to handle conditional logic.
- **Variables**: Declare and assign values to variables of types `char`, `int`, and `unsigned int`.
- **Variable Printing**: Print the values of `char`, `int`, and `unsigned int` variables using `printf`.
- **while Loops**: Learn how to use the `while` loop to repeat actions based on conditions.
- **ASCII Character Set**: Understand the concept of ASCII and how to work with character data.
- **GCC Flags**: Know the purpose of flags like `-m32` and `-m64` in the GCC compiler.

## Conclusion

This project provides a foundational understanding of essential C programming concepts such as variables, control structures (`if`, `else`, `while`), and operators.
